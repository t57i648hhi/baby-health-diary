# 出现蛋白尿，除了是肾脏病，还有可能是什么？

> 更新时间：2026-09-11 (UTC+8)

照例先说结论:不一定！虽然大多数蛋白尿是由肾脏病引起的，但仍存在其他原因引起的蛋白尿。

一、在了解病因之前，我们先了解下肾脏是如何产生蛋白尿的吧。

当血流流过肾脏时，相当一部分血液会流过一个叫“肾小体的地方”，肾小体是由肾小球毛细血管攀和肾小囊组成。

毛细血管袢简单理解就是肾脏最小的动脉团成一团。而肾小囊是又称鲍曼氏囊，包裹着肾小球。对于肾小球毛细血管袢有一个最重要的结构需要了解，就是滤过屏障。滤过屏障由三部分组成:内皮细胞窗孔（单层的内皮细胞上有很多小洞叫做窗孔，在横截面下，似乎内皮细胞是不完整的，但实际不是，那些空就是横截面切到的内皮细胞上的洞)、基底膜和最外层足细胞的足突（足细胞像是个八爪鱼爬在基底膜外侧伸出他的触角-足突，足突和足突间形成拉链样的结构，其中拉链的缝隙允许部分物质通过)三层组成，血液流过毛细血管袢的时候，水分和小分子物质会通过血管袢滤过屏障进入毛细血管腔形成尿的最初形态-原尿。那怎么就算是小分子物质呢，一般是小于6万9千道尔顿（69KD），69KD恰好就是白蛋白的分子量。白蛋白以及比白蛋白体积大的分子生理状态下不能通过滤过屏障，而比白蛋白小的分子包括小分子蛋白可以通过屏障进入原尿。因此，正常状态下在原尿中可以有蛋白，但是一般都是比白蛋白小的小分子蛋白（比如α微球蛋白、β微球蛋白、不完整的免疫球蛋白-轻链等）。那么为什么最终正常人的尿液中基本检不出蛋白呢（正常人尿液中蛋白并不是0)？是因为肾小管有重吸收的功能，会把肾小球滤过出来的蛋白重吸收入血（不光是小分子蛋白，对于肾小球滤过屏障受损患者漏出的白蛋白等大分子蛋白也会重吸收），导致最终的尿液中仅有极少蛋白。

当肾小球滤过屏障出问题的时候，不光小分子物质可以通过滤过屏障，白蛋白及更大分子蛋白（为了方便，本文中大分子蛋白定义为分子量＞白蛋白的蛋白)会从受损的滤过屏障进去原尿，其中相当部分会出现在终尿中（一部分会被肾小管重吸收)，这时就会出现蛋白尿。

同时，如果肾小管受损伤，重吸收出问题，则不能充分吸收原尿中小分子蛋白，也也会出现蛋白尿。

二、蛋白尿的分类及病因

了解了第一部分蛋白尿产生的机制后，就非常容易理解后续的内容了。

肾小球源性蛋白尿

指的就是肾小球滤过屏障受损后所导致的蛋白尿。这是临床上最常见的蛋白尿类型。它的特点是，尿蛋白的成分主要以白蛋白及大分子蛋白为主（一般至少要超过尿蛋白60％以上），尿蛋白的量可多可少，并与疾病严重程度相关。一般来说，在某一种疾病中，肾小球蛋白尿越多，病情越重（不同疾病间没有可比性）。常见的原因包括急性肾小球肾炎、各种慢性肾小球肾炎（IgA肾病、膜性肾病、微小病变性肾病、局灶节段硬化性肾小球肾炎等）、自身免疫所致肾小球疾病（其中最常见的是狼疮性肾炎）、糖尿病肾病等等。

2. 肾小管源性的蛋白尿

指肾小球滤过屏障没问题，但是肾小管受损伤，重吸收尿蛋白能力下降后引起的蛋白尿。这种蛋白尿的特点是:以小分子蛋白为主（小于白蛋白分子量,常见的是β2微球蛋白、α微球蛋白、尿溶菌酶、免疫球蛋白轻链等)；同时尿蛋白的量一般比较少（通常少于1g/24小时，绝对不会＞3.5g/24小时）；一般不会合并血尿；会有其他肾小管受损的表现（夜尿增多、肾小管酸中毒、尿糖阳性等）。常见的原因包括药物性肾损伤、自身免疫性疾病肾小管损伤（干燥综合征常见）、早期的高血压肾病等等。

3. 混合性蛋白尿

肾小球和肾小管损伤往往不是单独存在的，尤其是肾小球疾病疾病在晚期一般都会存在肾小管损伤，这时会同时出现肾小球性蛋白尿和肾小管性蛋白尿，称为混合性蛋白尿。

以上3种是由肾脏疾病所致蛋白尿，也是临床最常见的蛋白尿，基本占到蛋白尿的90％以上。接下来我们再谈几种不是肾脏本身出问题的蛋白尿。

4. 溢出性蛋白尿

什么是溢出性蛋白尿？之前我们说过了，肾小管可以重吸收小分子蛋白，但是它是有限度的，即使肾小管功能正常，如果血里面的某种小分子蛋白特别多，那么肾小球滤过的该蛋白也会等比例增加，当超过肾小管重吸收能力时，这些小分子蛋白就会出现在尿液中（好比一个杯子，当它破了口去装水肯定会漏，但是即使是杯子完好无损，但你倒得水过多，一样会溢出来)。这时候叫做溢出性蛋白尿。这种蛋白尿也是以小分子为主，有时候和肾小管性蛋白尿没那么好区分。主要靠以下几种办法来区别:首先，肾小管性蛋白尿量比较少，而溢出性蛋白尿量往往比较大（有时候也会比较小，这时区分就更困难)，甚至超过3.5g/24小时；其次，肾小管性蛋白尿中各种小分子都会有，但溢出性蛋白尿通常只有某一种（比如免疫球蛋白轻链、血红蛋白、肌红蛋白等)。溢出性蛋白尿并不常见，但之所以把它放在第一位来讲，是因为它的病因通常比较危险，一旦漏诊后果比较严重。溢出性蛋白尿常见病因有:多发性骨髓瘤（免疫球蛋白轻链）、横纹肌溶解（肌红蛋白）、溶血（血红蛋白），这些都不是肾脏疾病，但很多因为蛋白尿会被误收进肾内科。

5. 分泌性蛋白尿

Tamm－Horsfall 蛋白（THP）是由肾脏Henle髓袢升支与肾远曲小管的上皮细胞分泌的一种糖蛋白，在泌尿系感染等情况下会分泌增加，导致尿蛋白。这种往往在控制尿路感染后会随之消失。

6. 体位性蛋白尿

有些患者站立位时会出现蛋白尿，而平卧时尿蛋白会明显减少或者消失，这种叫体位性蛋白尿。这种通常是由于肾静脉受压所致。肾静脉在解剖结构上通过腹主动脉和肠系膜动脉之间的夹角，其外有脂肪组织包裹，当夹角过小或者脂肪组织过少时肾静脉就会被压迫。这时站立位时夹角会进一步变小，压迫加重，导致肾脏淤血，最终导致蛋白尿；而平卧时，夹角增大，肾淤血改善，尿蛋白减少。这种蛋白尿一般量比较少，而且站立加重，平卧减轻，肾脏彩超或者肾静脉造影可以诊断。这种情况通常见于青少年或者体格高瘦的人，一般随着发育就会改善，肾脏并无实质损害，对健康生命没有太大影响，平时注意不要久立或者过度运动。

三、尿蛋白检测

尿蛋白检测一般有以下几种方法:

定性检测

最常用的是尿常规。大多数医院尿常规里检测的蛋白是白蛋白，一般结果用+或者-表示，正常为-；同时会看到后面还有数值，通常单位是g/l，是个浓度单位，受尿液浓缩或者稀释影响，不能作为定量指标来判断疾病严重程度或者治疗反应，只能作为尿蛋白定性的筛查指标。

另外还有网上卖的尿蛋白试纸。也只能做尿蛋白定性，因此完全没必要买这种东西回家自己检测治疗效果。

2. 尿蛋白定量

尿蛋白定量一般可分为点定量和时间段定量。

临床上最常用的24小时尿蛋白定量就是时间段定量。收集全天24小时尿液，然后测定浓度和尿液体积，二者相乘就是尿蛋白总量（所以化验单上一般有三行指标，分别是尿蛋白浓度、尿液体积和24小时尿蛋白量，但需要关注的只是24小时尿蛋白量）。理论上这种方法是最可靠的金标准。但是实际操作中也存在很多问题，例如尿液未混匀导致浓度不均一，老年人记性差留少了尿等。另外，还有就是不方便，尤其对于门诊患者。现在很多医院为了安全（患者误服)，一般都不发防腐剂了，所以24小时尿蛋白如果在高温情况下会被细菌降解导致不准（我见过有人为了怕不准，把尿放在家里冰箱冷藏，这画面不敢想）。

所以，就有另外一种定量方法出现，就是点定量方法，临床上用的最多的是尿蛋白肌酐比值，只用留一次尿。因为在某个时间点检测的蛋白受尿液浓缩稀释影响，那么可以选一个每日排出恒定的指标来进行矫正，最简单的指标是尿肌酐，用尿肌酐来校正尿液稀释浓缩的影响。尿蛋白肌酐比值的化验单一般也包括3行，尿蛋白浓度、肌酐浓度和二者比值（只需看比值）。多数单位尿蛋白肌酐比值的单位是mg/g，在这个单位下，基本可以把尿蛋白肌酐比值和24小时尿蛋白化约等号（这只是巧合，并无特别因果关系)，例如尿蛋白肌酐比值是550mg/g，那么24小时尿蛋白定量通常会在500-600mg。这种方法就比较适宜门诊患者。但这种方法在肾功能中重度不全患者里就没那么准了（因为这时肌酐排出减少了)。

3. 蛋白类型检测

最简单的是同时做尿白蛋白定量检测和尿总蛋白定量检测看二者比值。

以前很多医院会做尿蛋白圆盘电泳，来看尿蛋白成分分布，现在很少有医院做了。更多的是做尿中蛋白成分定量，比如尿白蛋白、尿微球蛋白、尿轻链等（各个医院检查单开单的名称不一样）。
